# CleanTake

**Recover damaged dialogue from the recordings you already have.**

Your main microphone lost a word. Your backup recorded it. CleanTake is being built to find that real passage, align it, make the repair easy to hear and revise, and export dialogue with an editable record of every source switch.

## Development status

Active development. A stable release is not available yet. The complete supported workflow covers importing simultaneous recordings, synchronization and drift correction, damage review, contextual comparisons, reversible repairs, finishing and portable exports.

The core runs locally. It will not require an account, paid API or cloud upload. Missing speech is recovered only when it exists in one of your recordings.
